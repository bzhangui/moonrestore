# 工具链基线

## 0.2.0

最低 moonc 调整为 0.10.15（高于赛事 0.10.14 门槛）。新规范使用 Int32/UInt32 和带默认值的命名参数新格式，旧 formatter 的结果不能用来证明新 CI 的格式门禁。当前隔离验证基线为 moon 0.1.20261012 / moonc 0.10.15+943464bfa，SDK 仅放 `.local/toolchain`，不修改全局 SDK、不随源码发布。

`scripts/build.mjs` 统一导出 moon/moonEnv；构建、验证、打包与归档检查使用同一 SDK。优先级 MOON_BIN > 已有本项目私有 SDK > 系统 PATH；指定 MOON_BIN 时操作者负责匹配 MOON_HOME。首次构建先更新独立索引；SDK 不含凭据复制或自动登录。

以下为 0.1.0 历史基线，不代表 0.2.0 仍支持该旧工具链：

2026-10-09 核对官方稳定版发布清单 `https://cli.moonbitlang.com/version.json`：

- moon：0.1.20260920，914d7da
- moonc：v0.10.14+7d59c7ec9
- moonrun：0.1.20260920
- 依赖：moonbitlang/x 0.5.5，模块内显式固定版本
- 本机 Node：v24.15.0；工具运行要求 ≥ 22，CI 使用 22

0.1.0 CI 从官方安装器安装当时稳定版，并检查编译器不低于 0.10.14；0.2.0 已提高检查下限为 0.10.15。这不是永远冻结工具链的安装方案；上游稳定版变化可能触发兼容性维护，运行日志和便携包 manifest 会记录实际版本。不会使用不存在的日期下载路径来伪装“已固定”。

源码验证：`npm run validate`。核心四目标均检查、构建、测试；应用 JS 目标编译，文件系统测试在对应系统执行。Linux/macOS 的排他目录提交辅助程序需要 C 编译器，构建失败不会降级为不安全的普通重命名。

构建和验证脚本先执行 `moon update`，使全新机器获取注册表索引。首次依赖解析需要网络；固定的 x 0.5.5 不会因索引刷新自动变成其他版本。已构建的工具运行不需要访问注册表。

离线使用可用 `node scripts/package.mjs` 生成的平台运行包，要求 Node 运行时但不要求 MoonBit。包中含许可证、归属、操作说明及文件校验清单；不包含个人文件、凭据、Git 历史或本地备份。
