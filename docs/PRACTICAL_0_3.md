# 0.3.0 实用性与操作边界

## 任务可管理、失败可见

工作台支持编辑、暂停/恢复和删除配置。修改使用当前配置摘要确认，旧页面的操作会拒绝；删除配置不删除快照、源文件或恢复密钥，也不擅自删除已有系统计划。暂停任务会拒绝执行，恢复后再按到期状态处理。保存任务并不等于 OS 计划安装。

可选到期自动执行仅对显式勾选的任务生效，前提是 CLI 工作台/原生托盘仍在运行；检查间隔默认 15 秒，操作串行。Windows 系统计划仍使用原有显式预览/确认机制，要求当前用户登录。设备离线后最多重试 0..3 次，默认间隔 15 分钟；错误盘符/仓库身份不会自动接纳。若只由低频系统计划调用，实际重试时刻受该计划触发频率限制，不能承诺离线时准时运行。

备份、校验、演练和第二副本分别记录时间。主备份完成但后续校验/复制失败时，整个任务不能标为成功。新增或更换副本会清除旧的整体成功标记；编辑备份范围后重建相关基线，避免拿旧范围证明新配置已验证。

本机提醒保留最多 100 条，同任务同原因一小时内去重。Windows 桌面提醒需要任务显式开启，浏览器通知也需要权限；不承诺系统一定投递。没有邮件/Webhook/远程遥测，提醒不包含文件内容或源文件路径。

## 搜索、差异、批量与预览

- 历史列表每页 100 个，支持备注/ID 和严格 UTC 日期筛选；可以翻页访问完整历史，不默认丢弃旧版本。
- 跨历史文件搜索使用快照和条目游标，每批最多 200 个结果，绑定仓库状态；状态变化要求重搜，不建立持久化明文文件名索引。
- 当前版本可筛选文件、查看版本间内容差异，批量选择最多 128 个文件/子目录并恢复到一个全新目录。实际还受 64 KiB 请求体等预算约束。仍先完整验证整个快照，不因只选一份文件而掩盖其他损坏。
- 恢复确认绑定版本、目标、所选范围、权限选项及仓库状态；任意改变必须重新预览。不覆盖现有目标。小型 UTF-8 文本预览上限 128 KiB，逐块/整文件哈希验证，仅用 textContent 展示，不执行 HTML/脚本，也不把文件预览说成全仓库校验。

## 长任务

工作台操作与任务预算可设置 1..1440 分钟，默认 30 分钟；每个核心进程另有 3 分钟无进度超时。显示的是实际读写/校验计数和阶段，而不是猜测百分比。校验缓存命中时仍发出计算心跳，恢复仍核对文件哈希。

取消通过私有控制文件在核心 I/O/计算检查点协作完成，正常退出关闭文件和释放锁；10 秒内没有退出才强制终止，后者可能需要显式恢复锁/暂存。取消不是撤销：已提交的完整快照保留，没有提交的恢复不冒充完成。复制重试复用已有验证对象，不假定源文件在中断后仍未变化。

服务重启不伪造成功；仓库和任务锁按原恢复规则检查。临时进度不作为持久审计记录，完成结果和分别记录的证据时间才用于检查。

## 密钥与副本

密码/密钥路径只在工作台内存会话使用，30 分钟后不接受新操作；已开始的任务持有该次凭据直到结束，完成后丢弃引用。JavaScript 字符串无法承诺物理内存清零。服务停止或“忘记本次解锁”清除会话，不撤销已明确授权的 DPAPI 存储。密码不会写入 jobs.json、进度或报告。

恢复密钥导出需要确认新文件且必须位于仓库之外；“仅用恢复密钥演练”明确传入该文件，不依赖会话密码/DPAPI 回退。修改密码只重包装同一个仓库密钥，不撤销旧配置、旧密钥副本；真正换主密钥须复制到独立新加密仓库并演练。

可配置已初始化的第二副本仓库，完成主备份/校验/演练后执行完整源验证、逐对象复制及目标诊断，保留原历史且不传播删除。副本必须与源和主仓库不重叠，绑定仓库随机身份；加密副本另行解锁/授权 DPAPI，不保存密码。同物理磁盘警告来自 OS 报告，虚拟化/网络盘/无法识别时标为未知；不同磁盘编号不等于已证明独立灾备。

## 元数据、性能与尚未提供的能力

新快照可保存条目修改时间（毫秒精度）和基础 POSIX 模式，均在清单哈希内验证。默认恢复修改时间，权限继续采用私有默认值；只有明确勾选时才恢复 POSIX 0..0777 模式，不恢复 setuid/setgid、所有者、Windows ACL、ADS、xattrs 或根目录原属性。Windows 不宣称已恢复 ACL。

`Snapshot` 的公开构造字段不变。库作者需要保留扩展时配对使用 `encode_with_metadata` / `decode_metadata`；只对基础 Snapshot 重新编码不会自动保留未知元数据。原格式预算及旧仓库内容不改写。

Gear 查表保留已发布公式与分块边界；副本对已验证逻辑对象去重读取，仍做最终目标诊断。没有未经校验的跨运行哈希缓存。维护规划的累计清单模型限 64 MiB，超过拒绝而不是无限占内存；格式/条目/分块等原预算同时有效。

Brotli 原型对合成文本、随机二进制及 gzip 数据做过比率/耗时评估，但没有在仓库中启用压缩：需要独立的对象编码、解压预算和旧版本兼容设计。单次混合样本并未证明总体备份加速，不发布虚假加速比。

Windows VSS 仅提供只读服务/权限准备检查，未创建阴影副本，不是 VSS requester，也不提供数据库热备份。仍使用原来的变化检测；占用/变化文件失败时应关闭写入程序后重试。VSS writer 协调、特权快照生命周期、真实 NAS/断电/跨主机/长期生产是独立验证工作，不能以模拟替代。
