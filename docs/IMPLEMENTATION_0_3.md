# 0.3.0 实用性升级实施记录

目标：普通用户无需开发环境即可建立备份，失败可见、任务可控、历史可搜索、密钥可演练，保持旧仓库可读。

实施范围：内置运行时 Windows 包与启动/目录选择；任务编辑暂停删除、离线重试与通知；历史搜索/差异/多选恢复；真实进度与取消/预算；自动第二副本；加密/密钥恢复向导；分块热路径与混合样本基准；文件元数据、VSS 调研与兼容性/升级回退测试。

| 工作项 | 实现及验证边界 |
|---|---|
| 日常使用 | 原生托盘/当前用户安装、内置运行时与路径选择；非交互宿主验证，不冒充人工窗口验收 |
| 自动与提醒 | 到期执行需显式开启；离线有限重试、本机通知、分离证据时间；系统通知投递不作保证 |
| 查找与恢复 | 全历史游标、差异、文本预览、多选；预览与执行共用 MoonBit 规则 |
| 长任务 | 实际阶段计数、预算、协作取消/清理；取消不撤销完整提交 |
| 第二副本 | 自动完整验证复制、身份绑定；OS 磁盘关系不等于独立灾备证明 |
| 密钥向导 | 创建/解锁/导出/独立密钥演练/密码重包装；不伪称主密钥轮换 |
| 效率 | 保持边界的 Gear 查表、复制去重读取、模型预算；混合样本未证明整体加速，压缩只评估 |
| 元数据与平台 | 可选属性扩展、真实旧包双向内容恢复和配置回退测试；VSS 仅只读准备检查 |

实际结果与发布状态写入 QUALITY_REPORT、ACCEPTANCE 与 PUBLICATION。系统计划、原资料、真实阴影副本和用户密钥不会在测试中被擅自操作。真实设备、NAS、跨主机、断电及长期生产证据仍需实际条件，模拟不能替代。
