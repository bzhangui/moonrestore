# 三个应用场景

运行 `node examples/scenarios.mjs` 可复现下面的受控演练。全部使用程序生成的临时样本，不是真实用户试点、用户调研或生产效益证据。

## 1. 科研资料误改恢复

输入：中文文件名的论文、二进制实验数据、空目录。先备份第一稿，修改论文后再备份，列出差异并校验全部快照，再将第一稿恢复到新目录，断言内容一致。

价值：能找回误改/删除前的数据；验证恢复动作而不是只相信“备份成功”。实际部署时把仓库放到独立盘，并暂停原文件写入。

## 2. 团队资产版本备份

输入：共同素材和项目目录，排除缓存/临时目录。未修改文件时再次备份，断言新增对象字节为零；在文件中间插入内容后观察分块复用，并恢复新版验证。

价值：避免每次复制整套素材，节约存储。当前演练验证的是本地文件仓库；真实 NAS、跨主机和长期容量收益还需独立测试。

## 3. 批处理前的安全回滚

输入：导入数据和配置文件。批处理前备份，模拟错误修改/删除，恢复选定文件到新目录并逐字节比对。

价值：给导入、批量转换和脚本处理留下可恢复版本。工具不直接覆盖生产目录；确认恢复内容后由操作者决定如何替换。
