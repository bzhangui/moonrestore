# 验收进度（可复核证据，不是正式申报书）

当前开发源码为 0.5.0；本轮仅授权 GitHub 推送，不发布 Mooncakes，新 API 尚不能通过注册表获取。正式版仍为 0.3.0。以下区分本轮与历史证据，不等于赛事最终通过。

## 0.5.0 增量核查

第 1/3/4/6/7 项新增 MoonBit 状态/检查点规则、持久任务、统一应用计划、运输归档、可复现故障测试与 RELIABILITY_0_5 指南；旧核心接口和格式保持兼容。第 5 项增加一次性 PostgreSQL 实例 CI，真实客户端导出/SQL 恢复证据必须以对应提交成功结果为准。第 2 项本轮仅推送授权仓库；提交与远端结果见 PUBLICATION。第 9 项仍为 Apache-2.0，未引入 npm 运行库或移植第三方备份实现。第 8 项仍存在“源码新功能尚未发布到 Mooncakes”的缺口，按用户要求暂不发布，不能把 0.3.0 包称为 0.5.0。

并非所有远期功能都完成：分段 live manifest 与真实 VSS 请求器未实现；真实云商/独立硬件/长期生产未验证。运输归档和模拟故障有实际工程作用，但不能替代这些证据。下面为 0.4 及更早版本的历史记录。
