# 后续开发与验证路径

本轮开发以“备份是否完整、历史资料是否真正可恢复”为主线，保持 MoonBit 领域内核与系统适配分层。

1. 可导出健康报告、隔离恢复演练、容量与源变化预警。
2. 有界自动任务、本机工作台、版本选择与恢复预览。
3. 标准认证加密与独立仓库副本，保留旧仓库。
4. 默认预览的保留策略、显式确认与中断安全回收。
5. 大文件/目录资源预算、可重复性能探测与格式兼容。
6. 受控重复演练和真实资源验证清单。

## 0.2.0 交付范围

上面六项已形成可运行代码与回归入口：`report/drill/capacity`、`job-add/job-run` 和工作台、认证加密与 `replicate`、确认令牌绑定的隔离/恢复/七天后清理、格式 3 大文件 profile、重复/浏览器/实际 Windows 调度测试。具体结果见 [维护报告](QUALITY_REPORT.md)，发布证据见 [发布记录](PUBLICATION.md)。

保留的重要边界：工作台仅本机且串行；Windows 调度要求当前用户登录；默认格式预算不原地放宽；回收先隔离不立即释放空间；没有 S3 后端、通用跨平台密钥管理器或无限元数据规模。单步编排超时与安全操作见 [工作台说明](WORKBENCH.md)。

下一阶段应优先收集独立介质、第二主机解锁/恢复、真实 NAS 文件系统语义和周期性长期演练证据，再据实决定远程存储与更大清单格式，不能用更多模拟次数替代这些验证。

受控模拟不等于真实 NAS、断电、跨主机或外部用户试点。每项实际完成度、限制和测试结果以维护报告为准；不自动操作用户资料。公开源码推送和注册表发布仅在用户明确授权后执行，私人申报书、备份、恢复密钥和运行报告均排除。
